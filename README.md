## 📱 9 บริการหลักที่ฝังอยู่ในเมนูแอป (Embedded In-App Modules)

ทุกบริการสามารถใช้งานได้โดยตรงจากภายในแอปพลิเคชัน:

1. 🚗 **เมนูเรียกรถ (GrabCar / Grab Transport)**: ฝังพอร์ทัล Grab Transport และระบบเรียกรถด่วนพร้อม GPS ติดตามเส้นทางในเมนูแอป
2. 🍔 **เมนูสั่งอาหาร (GrabFood)**: ฝังพอร์ทัล GrabFood พร้อมระบบค้นหาร้านอร่อย สั่งอาหาร และตะกร้าสินค้าในเมนูแอป
3. 🛍️ **เมนูสั่งสินค้าออนไลน์ (Shopee)**: ฝังพอร์ทัล Shopee Online Shopping ช้อปปิ้งสินค้าออนไลน์ เครื่องใช้ไฟฟ้า IT และคำนวณผ่อน 0% ในเมนูแอป
4. 💡 **เมนูจ่ายบิลค่าไฟ/น้ำ (MEA & PEA e-Service)**: ฝังพอร์ทัล e-Service การไฟฟ้านครหลวง (MEA), การไฟฟ้าส่วนภูมิภาค (PEA) และสแกน QR PromptPay ฟรีค่าธรรมเนียมในเมนูแอป
5. 🚨 **เมนูเหตุด่วน SOS (One Stop Emergency)**: ปุ่มส่งสัญญาณฉุกเฉิน พิกัด GPS อัตโนมัติ พร้อมสายด่วน 191 / 1669 / 199
6. 🏠 **เมนูควบคุมบ้าน (One Stop IoT)**: สั่งเปิด-ปิดไฟ แอร์ และอุปกรณ์ Smart Home ภายในบ้าน
7. 🤖 **เมนูผู้ช่วย AI (AI Advisor)**: ตอบข้อสงสัยด้านการซ่อมบ้าน อาหาร สุขภาพ การเงิน ตลอด 24 ชม.
8. 📈 **เมนูตลาดหุ้น (One Stop Trade)**: ติดตามดัชนี SET Index, ราคาหุ้นรายตัว (PTT, CPALL, ADVANC) และกราฟเทคนิค
9. 📰 **เมนูข่าวสารบ้านเมือง (One Stop News)**: อัปเดตข่าวเด่น ข่าวเศรษฐกิจ การเมือง สังคม ทันเหตุการณ์

## 📲 วิธีติดตั้งเป็นแอปบนหน้าจอมือถือ (PWA Installation)

| ระบบปฏิบัติการ | ขั้นตอนการติดตั้ง |
|---|---|
| **📱 iPhone / iPad (Safari)** | 1. เปิดลิงก์ [https://fiatnoraset.github.io/ZOFIAT/](https://fiatnoraset.github.io/ZOFIAT/) ใน Safari<br>2. กดปุ่ม **แชร์** (Share icon ด้านล่าง)<br>3. เลือก **"เพิ่มไปยังหน้าจอโฮม"** (Add to Home Screen) |
| **🤖 Android (Chrome)** | 1. เปิดลิงก์ [https://fiatnoraset.github.io/ZOFIAT/](https://fiatnoraset.github.io/ZOFIAT/) ใน Chrome<br>2. กดปุ่ม **จุด 3 จุด** (มุมขวาบน)<br>3. เลือก **"ติดตั้งแอป"** (Install App) หรือ **"เพิ่มไปยังหน้าจอโฮม"** |
| **💻 Windows / Mac (Chrome / Edge)** | 1. เปิดลิงก์ในเบราว์เซอร์<br>2. กดปุ่ม **"ติดตั้งแอป PWA"** บนแถบ Header หรือไอคอนติดตั้งบน Address Bar |

## 🛠️ โครงสร้างไฟล์ของโครงการ (Project Structure)

```text
ZOFIAT/
├── index.html            # หน้าหลักแอปพลิเคชัน (PWA App Entry พร้อมบริการฝังในแอป)
├── standalone.html       # Single-file PWA Bundle
├── manifest.json         # PWA Manifest (กำหนดชื่อ, ไอคอน, สีธีม)
├── service-worker.js     # PWA Service Worker (ระบบ Offline Caching)
├── logo.jpg              # โลโก้แอป One Stop Service
├── icon-192.png          # ไอคอน PWA ขนาด 192x192
├── icon-512.png          # ไอคอน PWA ขนาด 512x512
├── tcpserver.ps1         # Web Server สำหรับรันบน Windows (Port 3000)
├── README.md             # เอกสารคู่มือและการใช้งาน
└── src/                  # ซอร์สโค้ด React & Tailwind Components
    ├── components/       # Header, Navigation
    └── modules/          # 9 Modules (Ride, Food, Mall, Bill, SOS, Home, AI, Stocks, News)
```
