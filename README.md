## 📱 9 บริการหลักภายในแอป (9-in-1 Features)

1. 🚗 **เรียกรถรับ-ส่ง (Grab Transport)**: เชื่อมต่อบริการเรียกรถด่วน มอเตอร์ไซค์ แท็กซี่ รถ VIP ไปยัง [Grab Transport](https://www.grab.com/th/transport/)
2. 🍔 **สั่งอาหาร (GrabFood)**: สั่งอาหารดิลิเวอรีร้านดังส่งตรงถึงบ้านไปยัง [GrabFood](https://www.grab.com/th/food/)
3. 🛍️ **สั่งสินค้าออนไลน์ (Shopee)**: เลือกซื้อสินค้าออนไลน์ เครื่องใช้ไฟฟ้า แฟชั่น อุปกรณ์ IT บน [Shopee](https://shopee.co.th/)
4. 💡 **จ่ายบิลค่าน้ำ-ค่าไฟ (One Stop Pay)**: เช็กยอดค่าน้ำ MWA / ค่าไฟ MEA สแกน QR PromptPay ฟรีค่าธรรมเนียม
5. 🚨 **แจ้งเหตุด่วน SOS (One Stop Emergency)**: ปุ่มส่งสัญญาณฉุกเฉิน พิกัด GPS พร้อมสายด่วน 191 / 1669 / 199
6. 🏠 **ควบคุมบ้านอัจฉริยะ (One Stop IoT)**: สั่งเปิด-ปิดไฟ แอร์ และอุปกรณ์ Smart Home ภายในบ้าน
7. 🤖 **ผู้ช่วย AI ให้คำปรึกษา (AI Advisor)**: ตอบข้อสงสัยด้านการซ่อมบ้าน อาหาร สุขภาพ การเงิน ตลอด 24 ชม.
8. 📈 **ตลาดหุ้น & การลงทุน (One Stop Trade)**: ติดตามดัชนี SET Index, ราคาหุ้นรายตัว (PTT, CPALL, ADVANC) และกราฟเทคนิค
9. 📰 **ข่าวสารบ้านเมือง (One Stop News)**: อัปเดตข่าวเด่น ข่าวเศรษฐกิจ การเมือง สังคม ทันเหตุการณ์

## 📲 วิธีติดตั้งเป็นแอปบนมือถือ (PWA Installation)

| ระบบปฏิบัติการ | ขั้นตอนการติดตั้ง |
|---|---|
| **📱 iPhone / iPad (Safari)** | 1. เปิดลิงก์ [https://fiatnoraset.github.io/ZOFIAT/](https://fiatnoraset.github.io/ZOFIAT/) ใน Safari<br>2. กดปุ่ม **แชร์** (Share icon)<br>3. เลือก **"เพิ่มไปยังหน้าจอโฮม"** (Add to Home Screen) |
| **🤖 Android (Chrome)** | 1. เปิดลิงก์ [https://fiatnoraset.github.io/ZOFIAT/](https://fiatnoraset.github.io/ZOFIAT/) ใน Chrome<br>2. กด **จุด 3 จุด** (เมนูมุมขวาบน)<br>3. เลือก **"ติดตั้งแอป"** (Install App) หรือ **"เพิ่มไปยังหน้าจอโฮม"** |
| **💻 Windows / Mac (Chrome / Edge)** | 1. เปิดลิงก์ในเบราว์เซอร์<br>2. กดปุ่ม **"ติดตั้งแอป PWA"** บนแถบ Header ของแอปพลิเคชัน |

## 🛠️ โครงสร้างไฟล์ของโครงการ (Project Structure)

```text
ZOFIAT/
├── index.html            # หน้าหลักของแอปพลิเคชัน (PWA App Entry)
├── standalone.html       # Single-file PWA Bundle
├── manifest.json         # PWA Manifest (กำหนดชื่อ, ไอคอน, สีธีม)
├── service-worker.js     # PWA Service Worker (ระบบ Offline Caching)
├── sw.js                 # Service Worker Alias
├── logo.jpg              # โลโก้แอป One Stop Service
├── icon-192.png          # ไอคอน PWA ขนาด 192x192
├── icon-512.png          # ไอคอน PWA ขนาด 512x512
├── tcpserver.ps1         # Web Server สำหรับรันบน Windows (Port 3000)
├── package.json          # รายการ Dependencies
└── src/                  # ซอร์สโค้ด React & Tailwind Components
    ├── App.jsx
    ├── main.jsx
    ├── components/       # Header, Navigation
    └── modules/          # 9 Modules (Dashboard, Ride, Food, Mall, Bill, SOS, Home, AI, Stocks, News)
```

## ⚡ วิธีรันเซิร์ฟเวอร์ในเครื่อง (Run Locally)

### ตัวเลือกที่ 1: รันด้วย PowerShell Server (Windows)
```powershell
powershell -ExecutionPolicy Bypass -File "tcpserver.ps1"
```
เปิดเบราว์เซอร์แล้วไปที่: `http://localhost:3000`

### ตัวเลือกที่ 2: รันด้วย Node.js / Vite
```bash
npm install
npm run dev
```
