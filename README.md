**One Stop Service** คือเว็บแอปพลิเคชัน Progressive Web App (PWA) ศูนย์รวมบริการอำนวยความสะดวกครบวงจร 9-in-1 ที่รวบรวมทุกบริการสำคัญ (GrabCar, GrabFood, Shopee, ชำระบิลค่าไฟ MEA/PEA, แจ้งเหตุฉุกเฉิน SOS, ควบคุมบ้าน IoT, และผู้ช่วย AI) ไว้ใน**หน้าหลักหน้าเดียว (Single-Page Dashboard)** ตัดหน้าเมนูย่อยออกทั้งหมดเพื่อความรวดเร็วและใช้งานง่ายที่สุด สามารถเปิดใช้งานได้ทุกอุปกรณ์ (iOS, Android, Windows, Mac, Tablet) ทันที!

## 📱 9 บริการหลักบนหน้าหลัก (Single-Page 9-in-1 Convenience Hub)

ทุกบริการสามารถใช้งานได้โดยตรงจากหน้าหลักทันที:

1. 🚗 **เมนูเรียกรถรับ-ส่ง (GrabCar / Grab Transport)**: กดเปิด Grab Transport เพื่อเรียกรถด่วน แท็กซี่ หรือมอเตอร์ไซค์ได้ทันที
2. 🍔 **เมนูสั่งอาหาร (GrabFood)**: กดเปิด GrabFood สั่งอาหารร้านเด็ดส่งตรงถึงบ้าน
3. 🛍️ **เมนูสั่งสินค้าออนไลน์ (Shopee)**: กดเปิด Shopee ช้อปปิ้งสินค้าออนไลน์ เครื่องใช้ไฟฟ้า IT และโปรโมชันสุดคุ้ม
4. 💡 **เมนูจ่ายบิลค่าไฟ/น้ำ (MEA & PEA)**: สแกน QR PromptPay ชำระค่าไฟฟ้า (1,820.00 ฿) และลิงก์ตรง e-Service การไฟฟ้านครหลวง (MEA) / การไฟฟ้าส่วนภูมิภาค (PEA)
5. 🚨 **เมนูเหตุด่วน SOS (191 / 1669)**: ปุ่มกดส่งสัญญาณฉุกเฉินพร้อมพิกัด GPS อัตโนมัติ และปุ่มโทรด่วน 191 (ตำรวจ) / 1669 (พยาบาล)
6. 🏠 **เมนูสั่งเปิด-ปิดบ้าน IoT**: ควบคุมสวิตช์ไฟ แอร์ Smart TV และประตูรั้วได้สดๆ บนหน้าหลัก
7. 🤖 **เมนูผู้ช่วย AI ปรึกษา (AI Advisor)**: เปิดหน้าต่างแช็ตถาม-ตอบ AI ปรึกษาปัญหาบ้าน อาหาร สุขภาพ การเงิน ตลอด 24 ชม.
8. 📈 **เมนูตลาดหุ้น (SET Index)**: ติดตามดัชนีตลาดหุ้น SET และหุ้นเด่น (PTT, CPALL, ADVANC, DELTA) บนหน้าหลัก
9. 📰 **เมนูข่าวสารบ้านเมือง**: สรุปข่าวเด่นประจำวันทั้งเศรษฐกิจ การเมือง สังคม บนหน้าหลัก

## 📲 วิธีติดตั้งเป็นแอปบนหน้าจอมือถือ (PWA Installation)

| ระบบปฏิบัติการ | ขั้นตอนการติดตั้ง |
|---|---|
| **📱 iPhone / iPad (Safari)** | 1. เปิดลิงก์ [https://fiatnoraset.github.io/ZOFIAT/](https://fiatnoraset.github.io/ZOFIAT/) ใน Safari<br>2. กดปุ่ม **แชร์** (Share icon ด้านล่าง)<br>3. เลือก **"เพิ่มไปยังหน้าจอโฮม"** (Add to Home Screen) |
| **🤖 Android (Chrome)** | 1. เปิดลิงก์ [https://fiatnoraset.github.io/ZOFIAT/](https://fiatnoraset.github.io/ZOFIAT/) ใน Chrome<br>2. กดปุ่ม **จุด 3 จุด** (มุมขวาบน)<br>3. เลือก **"ติดตั้งแอป"** (Install App) หรือ **"เพิ่มไปยังหน้าจอโฮม"** |
| **💻 Windows / Mac (Chrome / Edge)** | 1. เปิดลิงก์ในเบราว์เซอร์<br>2. กดปุ่ม **"ติดตั้งแอป PWA"** บนแถบ Header หรือไอคอนติดตั้งบน Address Bar |

## 🛠️ โครงสร้างไฟล์ของโครงการ (Project Structure)

```text
ZOFIAT/
├── index.html            # หน้าหลักแอปพลิเคชัน (PWA App Entry พร้อมบริการฝังในแอป)
├── standalone.html       # Single-file PWA Bundle
├── manifest.json         # PWA Manifest (กำหนดชื่อ, ไอคอน, สีธีม)
├── service-worker.js     # PWA Service Worker (ระบบ Offline Caching)
├── logo.jpg              # โลโก้แอป One Stop Service
├── icon-192.png          # ไอคอน PWA ขนาด 192x192
├── icon-512.png          # ไอคอน PWA ขนาด 512x512
├── tcpserver.ps1         # Web Server สำหรับรันบน Windows (Port 3000)
├── README.md             # เอกสารคู่มือและการใช้งาน
└── src/                  # ซอร์สโค้ด React & Tailwind Components
    ├── components/       # Header, Navigation
    └── modules/          # 9 Modules (Ride, Food, Mall, Bill, SOS, Home, AI, Stocks, News)
```
